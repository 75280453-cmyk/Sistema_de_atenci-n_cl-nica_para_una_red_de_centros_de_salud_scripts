# Sistema_de_atenci-n_cl-nica_para_una_red_de_centros_de_salud_scripts
Sistema de atención clínica para una red de centros de salud. Incluye arquitectura MVC con patrones DAO, Controller y Entity, microservicios y nube. Gestiona admisión, agenda médica, triaje y portal del paciente. Aplica principios de Nielsen, psicología del color y plan de pruebas. Prototipado en Figma.
